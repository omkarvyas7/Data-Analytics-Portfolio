# Voice of the Customer and CTQ Tree

Data is synthetic. The VOC below is simulated. It draws on four sources: resale customer complaints and reviews, Finance recovery reports, site operations leaders and the sustainability program.

## From customer comments to CTQs

| Customer / stakeholder | What they said (VOC) | Need | CTQ | Measure | Target |
|---|---|---|---|---|---|
| Resale buyer | "Bought as new, it was clearly opened and missing the charger." | Condition matches listing | Upgrade misgrade rate | Upgrade defects / audited units; complaint rate | Complaint rate down 40% |
| Finance partner | "Too much recovery value goes to liquidation for items that could be resold." | Recover maximum value | Recovery rate | Achieved $ / potential $ | >= 97.0% |
| Sustainability program | "We should not shred anything resellable." | Zero avoidable waste | Waste units | Resellable units sent to recycle/destroy per 10k | -50% vs baseline (44.1) |
| Returns Operations Manager | "Graders are not sure how to call open-box electronics; every site does it differently." | Clear, standard grading criteria | Disposition defect rate | Defects / audited units, DPMO | <= 3.5% |
| Site shift leads | "January backlog means units sit on the floor for a day before grading." | Timely disposition | Dock-to-disposition hours | Mean, p95, % > 48 h SLA | Mean <= 12 h, < 1% over SLA |
| New associates | "Training was mostly shadowing; I learned the open-box rules by getting audited." | Usable job aids | New-hire defect rate | Defect rate for tenure < 30 days | Halve vs baseline (13.2%) |

## CTQ tree

| Need | Driver | CTQ |
|---|---|---|
| The right disposition, first time | Correct condition grade | Defect rate <= 3.5%, DPMO, first-pass yield >= 95% |
| The right disposition, first time | Correct open-box / electronics call | Electronics defect rate, open-box defect rate |
| The right disposition, first time | Evidence captured | Photo step completion >= 95% |
| Maximum value recovered | No downgrades of resellable units | Recovery rate >= 97.0%, waste units per 10k |
| Maximum value recovered | No upgrades that come back | Upgrade misgrade share, complaint rate |
| Timely flow | Short queues | Queue-to-grade hours, mean dock-to-disposition <= 12 h, % over 48 h SLA |
